# Z3 Kernel v5 — Parent-Love Representational Sufficiency

This kernel tests the pre-registered parent-Love architecture before any claim
of theological isomorphism. It asks whether the declared relational model can
distinguish voluntary union from coercive binding, whether its proposed
conditions are load-bearing, whether current Fruit observables are label-unique,
and whether the repaired Cornell effective potential has the claimed algebraic
structure.

It does **not** prove that the encoded predicate is theological Love. Passing
means only that the frozen candidate definitions have the expected logical
consequences and countermodels.

From the repository root:

```powershell
py -m pip install -r Z3_VALIDATION/requirements.txt
py Z3_VALIDATION/kernel_v5/kernel_v5.py
```

Use repeated `--source` arguments to hash the pre-test ledger and canonical
derivation into the receipt.
