# Z3 Kernel v4

This package checks five salvation/status obligations with full `2x2` matrix
equations where applicable and explicit finite transition relations. It writes
a JSON receipt and exits nonzero if a result differs from its declared rail.

From the repository root:

```powershell
py -m pip install -r Z3_VALIDATION/requirements.txt
py Z3_VALIDATION/kernel_v4/kernel_v4.py
```

Or use `RUN_V4.ps1` / `RUN_V4.bat`.
